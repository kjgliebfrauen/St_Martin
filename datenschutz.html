2. Hosting durch GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Seiten werden technisch erforderliche Verbindungsdaten verarbeitet, damit die Website ausgeliefert und der sichere Betrieb gewährleistet werden kann. Dazu können insbesondere IP-Adresse, Datum und Uhrzeit des Abrufs, angeforderte Seite, Referrer sowie Angaben zu Browser und Betriebssystem gehören. Anbieter ist GitHub, Inc. Dabei kann eine Verarbeitung auch in den USA stattfinden.

Die Liedübersicht und die Liedtexte werden als statische Dateien von diesem Hosting ausgeliefert. Die Website verwendet keinen eigenen Analyse- oder Werbedienst und setzt selbst keine Analyse-Cookies.

3. Externe Schriftarten und PDF.js

Für die Gestaltung bindet diese Website Schriftarten von Google Fonts ein. Beim Laden der Schriftarten wird eine Verbindung zu Google-Servern hergestellt; dabei wird insbesondere Ihre IP-Adresse übermittelt. Auf der Upload-Seite wird außerdem die JavaScript-Bibliothek PDF.js von cdnjs (Cloudflare) geladen. Dabei wird eine Verbindung zu den Servern dieses Dienstes hergestellt.

Eine ausgewählte PDF-Datei wird im Browser verarbeitet und nicht durch diese Website hochgeladen. Die PDF-Inhalte werden daher nicht an Google Fonts oder cdnjs übermittelt.
